# Biblioteca Universitária

TP1 de Projeto de Bloco em Desenvolvimento Back-end  
Igor Pacheco Santos · 26T4-ENG-R1C2N1L1-DVBE-L5

O protótipo de console consulta empréstimos ativos usando registros de exemplo.
Ele exibe o exemplar, o prazo de devolução, o total de empréstimos ativos e as
vagas restantes até o limite de três.

Abra `BibliotecaUniversitaria.slnx` no Visual Studio com o SDK .NET 10 e execute
com Ctrl+F5. Pelo terminal, na raiz do repositório, use:

```powershell
dotnet run --project src/BibliotecaUniversitaria.csproj
```

Matrículas de exemplo: `2024001`, `2024002` e `2024003`. Digite `0` para sair.

O [PDF em docs](docs/TP1_Igor_Pacheco_Santos_26T4-ENG-R1C2N1L1-DVBE-L5.pdf) inclui
os requisitos, o diagrama UML, as especificações dos casos de uso e a
justificativa de escopo.
